# Security Policy

## Supported Versions

Please report security vulnerabilities for supported versions below:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within `manggala/laravel-dashboard-builder`, please send an email to Ilham Hatta Manggala at `ilhamhattamanggala@gmail.com`.

Please do **NOT** report security vulnerabilities through public GitHub issues.

### What to include in your report:
- Type of issue (e.g. SQL injection, XSS, RCE, authorization bypass).
- Full steps to reproduce the vulnerability.
- Proof-of-concept code or payload if available.

### Disclosure Policy:
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide an estimated timeframe for addressing the vulnerability.
- Once a fix is released, we will publicly credit you in the release notes unless you request anonymity.
